## xAI Pricing Reference (checked 2026-10-17, per 1M tokens, input / output)
- grok-4.3, grok-4.20-*: $1.25 / $2.50, 1M context — cheapest general option, 20% off via Batch API.
- grok-4.5 / 4.6 / 4.7: $2.00 / $6.00, 500k context.
- Prompts ≥200k tokens bill the whole request at 2×.
- Cost estimate for ELYRA (~3k input + ~500 output tokens per chat turn): grok-4.3 ≈ $0.005/turn (~$5 per 1k turns); grok-4.7 ≈ $0.009/turn (~$9 per 1k turns). Output is where 4.3 saves most (58% cheaper).
- Cost levers: keep system prompt + memories as a stable prefix so repeated history bills at cached-input rate ($0.20/1M on 4.3, 6× cheaper); use Batch API (−20%, 4.3/4.20 only) for background jobs like memory summaries, not live chat.
- Observed: a tiny test prompt still billed ~212 input tokens (hidden provider overhead). Check real usage in console.x.ai before finalizing budgets.
- Leaning: grok-4.3 as default cloud model for cost; quality vs grok-4.7 not yet compared side by side.
